Jaise main apne hi system ko samajh nahi paa raha.

Log kehte hain “you’ve changed.”

Main kehta hu “haan shayad.”

Lekin sach yeh hai… main nahi jaanta change hua hu ya

sirf distant ho gaya hu.

Aur yeh difference mujhe darata bhi nahi… bas

thaka deta hai.

Kabhi kabhi main sochta hu… ki agar main kisi din

completely feel karna shuru kar du… toh kya main wapas wahi

ho jaunga jo main tha?

Ya phir main itna door aa chuka hu… ki

wapas jaana possible hi nahi hai.

Main jawab nahi jaanta.

Aur shayad isi liye main questions kam poochne laga hu.

Kyunki har question ek aur layer khol deta hai… jahan

main already thoda lost hu.

Ab main zyada zindagi ko explain nahi karta.

Main bas usko observe karta hu.
