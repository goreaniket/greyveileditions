Aur dheere dheere ek strange shift hota hai…

tum physically yahan hote ho…

par emotionally tum kahin aur anchored hote ho.

Aur ye anchoring tum consciously nahi karte…

ye automatic hoti hai.

Kyuki mind repetition ko safety samajhta hai.

Aur jab koi memory baar baar replay hoti hai…

toh wo sirf memory nahi rehti…

wo reference point ban jati hai.

Aur har present moment us reference ke against compare hone lagta hai.

Isliye present kabhi fully satisfy nahi karta…

kyuki wo past jaisa “constructed perfection” nahi hota.

Aur jab comparison continuous ho jata hai…

toh present lose hone lagta hai importance.

Aur tum notice bhi nahi karte ki kab tum reality se thoda shift ho gaye ho…

kyuki tum function kar rahe hote ho normally.

Par andar ek silent substitution hoti rehti hai:

reality → memory
