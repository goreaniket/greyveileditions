Wahi memory jo pehle chest mein pressure ban jaati thi.

Wahi memory jo pehle ek hundred questions le aati thi.

Aur achanak...

kuch different feel hota hai.

Memory wahi hai.

Lekin interrogation gayab hai.

Courtroom khaali hai.

Koi evidence collect nahi ho raha.

Koi judgement pass nahi ho rahi.

Koi final conclusion nahi dhoonda ja raha.

Bas ek memory hai.

Aur pehli baar...

woh memory sirf memory lagti hai.

Na enemy.

Na mystery.

Na unfinished business.

Bas kuch jo hua tha.

Aur shayad yahi healing ka woh part hai jise log samajhte nahi.
